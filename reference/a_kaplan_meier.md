# a_kaplan_meier

**\[deprecated\]** Use
[`tern::a_surv_time()`](https://pharmaverse.github.io/tern/latest-tag/reference/survival_time.html)
instead.

## Usage

``` r
a_kaplan_meier(
  df,
  .var,
  ...,
  .stats = NULL,
  .formats = NULL,
  .labels = NULL,
  .indent_mods = NULL
)
```

## Arguments

- df:

  (`data.frame`) input data.

- .var:

  (`string`) variable name.

- ...:

  additional arguments (ignored).

- .stats:

  (`character`) statistics to compute (ignored).

- .formats:

  (`list`) formats for statistics (ignored).

- .labels:

  (`list`) labels for statistics (ignored).

- .indent_mods:

  (`list`) indentation modifications (ignored).
